# NFT Preview Card Component

This project is a solution to the [Frontend Mentor](https://www.frontendmentor.io/) challenge: **NFT Preview Card Component**. The challenge involves building a card component that displays NFT details such as an image, title, description, price, time remaining, and creator information.

## Overview

This project is designed to:

- Practice HTML and CSS skills.
- Use hover effects for interactive design.
- Implement a clean and responsive layout suitable for various screen sizes.

![Preview of the Component](./preview.jpg)

---

## Features

- Displays an NFT image with an overlay and an SVG eye icon on hover.
- Highlights the title text when hovered.
- Includes responsive styling and smooth hover transitions.
- Provides Ethereum price and time left, styled distinctly.
- Creator information with hover interaction on the creator's name.

---

## Technologies Used

- **HTML5**: Markup structure for the component.
- **CSS3**: Styling, layout, hover effects, and transitions.

## Structure

### HTML
The main structure includes:

- A card container (`<main>`) with the following:
  - An image container with overlay and SVG icon.
  - Title and description texts.
  - Ethereum price and time left.
  - Creator information.

### CSS
- Global reset and font setup.
- Flexbox for layout alignment.
- Hover effects for image overlay and title.
- Color scheme based on HSL values for consistency.
